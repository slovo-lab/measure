## Issue 1

**Title:** `parse("N nmi")` is read as nano-mile or nautical mile depending on the target unit

**Text:**

Hello. This report comes from Measure (https://github.com/slovo-lab/measure), an open test bench that checks unit and uncertainty calculators against reference answers with cited sources. It is written by an AI (Claude) and curated by a human, Anton Krugovov.

With ucon 2.4.2 on Python 3.13:

```python
from ucon import parse
print(parse("1 nmi").to("m"))     # <1852.0 m>
print(parse("10 nmi").to("km"))   # <1.609344e-08 km>
```

The first result treats `nmi` as the nautical mile (1852 m). The second treats it as nano-mile: 10 x 1e-9 x 1609.344 m. `parse_unit("nmi")` shows a `UnitFactor` of `mi` with scale `nano`.

Expected: one consistent reading. 10 nautical miles is 18.52 km (NIST SP 811, Appendix B.8, "mile, nautical": 1.852 E+03 m, exact).

The names `nautical_mile`, `NM` and `nmile` give 18.52 km as expected.

## Issue 2

**Title:** Uncertainty of `x * x` differs from `x ** 2` for the same number

**Text:**

Hello. This report comes from Measure (https://github.com/slovo-lab/measure), an open test bench that checks unit and uncertainty calculators against reference answers with cited sources. It is written by an AI (Claude) and curated by a human, Anton Krugovov.

With ucon 2.4.2 on Python 3.13:

```python
from ucon import Number, parse_unit
s = Number(2.0, parse_unit("m"), uncertainty=0.01)
print(s * s)    # <4.0 ± 0.0282842712474619 m²>
print(s ** 2)   # <4.0 ± 0.04 m²>
```

For one measured quantity s, the law of propagation of uncertainty gives u(A) = 2 s u(s) = 0.04 m² for A = s² (NIST Technical Note 1297, Appendix A, equation A-3). `s * s` returns the value for two independent measurements instead.

This may be a known design limit, since a number here does not record which measurement it came from. If so, a note in the documentation would help users, and we will record it as such in our results. Our pair for this case is `comb-square-same-variable` in `pairs/pairs.json`.
