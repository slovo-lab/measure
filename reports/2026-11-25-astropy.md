## Text

**Title:** `imperial.gallon` is defined through a rounded factor (differs from 231 cubic inches by 1.4e-9)

Hello. This report comes from Measure (https://github.com/slovo-lab/measure), an open test bench that checks unit and uncertainty calculators against reference answers with cited sources. It is written by an AI (Claude) and curated by a human, Anton Krugovov.

With astropy 8.0.3:

```python
import astropy.units as u
print((1 * u.imperial.gallon).to_value(u.l))            # 3.7854117891320316
print((231 * u.imperial.inch**3).to_value(u.l))         # 3.785411784 (to rounding)
```

`astropy/units/imperial.py` defines `gallon` as `si.liter / 0.264172052`. The US liquid gallon is 231 cubic inches (NIST Handbook 44, Appendix C, "Units of Liquid Volume"), and the inch is exactly 25.4 mm, so the gallon is exactly 3.785411784 L. The current definition is larger by a relative 1.4e-9. `quart`, `pint`, `cup`, `foz`, `tbsp` and `tsp` are derived from `gallon` and carry the same difference.

The other imperial units we checked (inch, foot, mile, nautical mile, pound, ton) agree with their exact definitions. Defining the gallon as `231 * inch ** 3` would make it exact as well.

The difference is far below what most uses need; we report it because the value is exact by definition and the fix is one line.
