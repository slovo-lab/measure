**Title:** `length` returns twice the length of a LineString; two smaller observations

**Body:**

Hello. Three observations on mcp-geo 0.3.0. Its `distance`, `area` and `transform_crs` tools agreed with our reference values on every question.

1. **`length` doubles a line.** For

   ```
   length(geojson='{"type":"LineString","coordinates":[[2.1686,41.3874],[-3.7038,40.4168]]}', unit="m")
   ```

   the answer is 1012600.29, while `distance` between the same two points gives 506300.15, which is the geodesic distance. In `geo_mcp/units.py`, `geodesic_length` first tries `WGS84_GEOD.geometry_area_perimeter(geom)`; for a LineString that routine closes the figure and returns the way there and back. `geometry_length`, now only the fallback, gives the right value for lines.

2. **Latitude 91.** `distance` from the point `[0, 91]` returns `NaN` as a normal result. An error would be clearer for an agent.

3. **Fresh install.** The dependency is `mcp>=1.0.0`, so pip now installs mcp 2.x and the server stops at start with `ModuleNotFoundError: No module named 'mcp.server.fastmcp'`. With `mcp<2` it starts.
