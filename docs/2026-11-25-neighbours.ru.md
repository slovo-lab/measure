# Кто ещё проверяет инструменты для ИИ-агентов и чем отличается Measure

*English version: [2026-11-25-neighbours.md](2026-11-25-neighbours.md)*

Написал Claude (ИИ) 25 ноября 2026 года, после просьбы владельца лаборатории проверить конкурентов. Три поиска сегодня в дополнение к поиску 24 ноября ([`2026-11-24-new-checks-prior-art.ru.md`](2026-11-24-new-checks-prior-art.ru.md)). Страницы прочитаны в виде выдержек из результатов поиска. «Не найдено» значит: не найдено в этих поисках.

| Вид | Найденные примеры | Что измеряют | Есть ли модель посередине | Сверяют ли число с эталоном, у которого есть источник |
|---|---|---|---|---|
| Тесты агентов, пользующихся инструментами | MCP-Bench, MCP-Atlas (36 серверов, 1 000 задач), MCP-AgentBench, MCP-Universe, MCPMark, MedMCP-Calc (медицинские калькуляторы) | Выбирает ли языковая модель нужный инструмент и приходит ли к верному ответу | Да; она и есть предмет | Нет: инструмент считается верным |
| Оценки качества серверов | mcpscore (72 правила; сообщает, что никогда не вызывает инструмент), mcp-scorecard (10 проверок, балл из 100), платформа, оценившая 39 752 сервера, оценщики описаний инструментов, agent-eval (12 серверов, судья — модель) | Протокол, схемы, описания, безопасность, установку | Иногда | Нет |
| Проверки «работает ли» | MCP Verified (еженедельно), Digital Applied, The Ops Log | Устанавливается, запускается, отдаёт список инструментов | Нет | Нет |
| Наборы для тестов самих авторов | mcp-assert, mcp-test-harness | То, что автор запишет как тест | Нет | Только если автор сам его даст |
| Точность с моделью в цепочке | mcp-data-check | Модель и сервер вместе, допуск 5% | Да | С таблицей, которую даёт пользователь |
| Метод, который Measure заимствует, в другой области | TraCIM (метрологические программы), статистические эталонные наборы NIST | Численную правильность по эталонным данным | Нет | Да, но не для инструментов, которые дают агентам |

**Чего не найдено:** никого, кто задавал бы вопросы с эталонными ответами и источниками прямо калькуляторам, которые вызывают агенты, по многим инструментам сразу, и публиковал бы ответ каждого. Это место и занимает Measure.

**Что из этого следует, если говорить честно:**

1. Соседей много, и они известнее этой лаборатории. Читатель спросит: «это разве не MCP-Bench?» Первый абзац каждого отчёта должен отвечать: модели нет, у каждого ответа есть эталон с источником, допуски до 1e-12.
2. Соседи продают балл. Один найденный сегодня сервер носит значок «86 из 100» от такой оценки, не запускается после свежей установки и пересчитывает фунт с шестью знаками. Балл за форму ничего не говорит о числе. Measure балла не даёт, и это причина так и оставить.
3. Два ближайших родственника по методу находятся в метрологии, а не среди инструментов для ИИ. Именно этим людям стоит прочитать отчёт первого раунда.
