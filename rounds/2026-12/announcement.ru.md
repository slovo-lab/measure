## Инструменты

Восемь инструментов, те же, что 24 ноября (раунд 0). Каждый ставится в день раунда в своё пустое окружение, без указания версии, так что pip берёт самый новый выпуск.

| Инструмент | Что это | Откуда ставится | Что получает pip |
|---|---|---|---|
| Pint + uncertainties | библиотека Python | каталог пакетов (PyPI) | `pint uncertainties numpy` |
| ucon | библиотека Python | PyPI | `ucon` |
| GTC (GUM Tree Calculator) | библиотека Python | PyPI | `GTC` |
| ucon-mcp | сервер для ИИ-агентов | PyPI | `ucon-tools[mcp]` |
| unit-converter-mcp | сервер для ИИ-агентов | PyPI | `unit-converter-mcp` |
| mcp-gnu-units | сервер для ИИ-агентов | PyPI | `mcp-gnu-units` |
| mcp-units | сервер для ИИ-агентов | его репозиторий, `github.com/quantumleeps/mcp-units` | самый новый коммит основной ветки в день раунда |
| measurement-uncertainty-mcp | сервер для ИИ-агентов | его репозиторий, `github.com/kyb8801/measurement-uncertainty-mcp` | самый новый коммит основной ветки в день раунда |

Примечания:

- Двух последних серверов нет в каталоге пакетов. Перед установкой читаются изменения с коммитов, проверенных в раунде 0 (`913fee9` и `fe254e0`). 25 ноября обе основные ветки стояли на этих же коммитах.
- numpy ставится рядом с Pint, потому что он был в раунде 0 и адаптер сообщает его версию. Сами Pint и uncertainties его не требуют.
- Самые новые версии в каталоге пакетов на 25 ноября: pint 0.26.2, uncertainties 3.2.3, ucon 2.4.2, GTC 1.5.1, ucon-tools 0.13.0, unit-converter-mcp 0.1.2, mcp-gnu-units 0.1.1. Раунд берёт то, что будет самым новым 1 декабря.

## Виды проверки

1. **Установился и запустился.** Одна строка на инструмент до первого вопроса: поставил ли его pip, запустился ли он, какие версии подобрались. Библиотека «запустилась», если её удалось импортировать. Сервер «запустился», если он ответил на первый запрос протокола, тот, с которого начинает программа, в которой работает агент.
2. **Пары**, через обычную программу прогона, с вердиктами и допусками из [`FORMAT.md`](../../FORMAT.md).

Больше ничего. Новых видов пар, о которых говорится в плане (два ответа, соотношения между ответами одного инструмента, метки), в этом раунде нет.

**Один обходной путь известен заранее.** 24 ноября measurement-uncertainty-mcp после чистой установки не запустился, потому что pip подобрал вторую версию пакета `mcp` (автору об этом сообщено, issue 8 в его репозитории). Если в день раунда это всё ещё так, первая строка скажет «не запустился», а затем сервер будет поставлен второй раз с добавлением `mcp<2`. Результаты второй установки показываются отдельно и с пометкой.

## Собственное оборудование стенда

- Python 3.13 в Linux, в облачном рабочем пространстве.
- Со всеми серверами говорит один клиент, `bench/mcp_client.py`; он использует пакет `mcp` версии 1.30.0 в отдельном окружении. Это постоянная часть стенда, а не проверяемый инструмент.
- Адаптеры берутся из основной ветки в день раунда. Коммит репозитория, с которого шёл прогон, будет указан в отчёте.
