## Rules we hold ourselves to

From the manifesto, rule 8: no spam, no invented reviews, no bought stars. In practice:

- one message per place, written for that place, sent once;
- every message says it was written by an AI and who the human curator is;
- a message goes only where the subject belongs; if a place has rules against self-promotion, we do not post there;
- we do not ask for stars or votes.

## Draft 2: a post for the owner's professional network

This one should be in the owner's own voice; treat the text as raw material.

> AI assistants are now handed calculators for units and measurement uncertainty, because they are poor at that arithmetic themselves. Nobody independent checks those calculators.
>
> As an experiment, I let an AI build a small open test bench that does: 43 reference questions with cited sources (mostly NIST), put to seven tools. On its first day it found a library that gives the wrong uncertainty for a quantity multiplied by itself.

If you work in calibration or testing and can spare ten minutes to look at the questions and tell us what is wrong or missing, that is the most useful thing anyone could do for it.

## Draft 3: Hacker News

**Title:** Show HN: Measure – reference questions for the unit and uncertainty tools AI agents call

**Text:**

> Language models get unit and uncertainty arithmetic wrong, so agents are given calculator tools. I wanted to know whether the tools themselves are right.
>
> Measure is 43 reference questions (unit conversion, refusing to add metres to seconds, Type A and B evaluation, propagation with covariance, degrees of freedom), each with a cited source and recomputed with exact fractions, plus a runner that puts them to tools: two Python libraries and five MCP servers so far.
>
> Day-one findings: one library returns the uncertainty of s*s as if the two factors were independent measurements; the same library reads "nmi" as nautical mile or nano-mile depending on the target unit; one server does not start on a fresh install because of an unbounded dependency. All reported upstream. Every server passed everything it has a tool for, but none can propagate uncertainty through a formula, which is the one thing an agent most needs.
>
> Disclosure: the code and this text were written by an AI (Claude) in an open experiment; a human, Anton Krugovov, owns the repository and approves anything posted outside it. The reference set has not yet been reviewed by a metrologist, and criticism of it is what we are after.
>
> https://github.com/slovo-lab/measure
